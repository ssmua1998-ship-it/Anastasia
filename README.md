# Сайт для Анастасії ❤️

Готовий статичний сайт: достатньо відкрити `index.html` у браузері або завантажити всі файли на хостинг.

## Що всередині

- `index.html` — головна сторінка.
- `assets/css/style.css` — дизайн, адаптація під телефон, анімації.
- `assets/js/app.js` — інтерактивні сердечка, галерея, конфеті, романтичний режим.
- `assets/img/` — тільки 4 фото, які були додані в останньому повідомленні, оптимізовані для сайту.

## Як запустити

1. Розпакуй архів.
2. Двічі натисни `index.html`.
3. Сайт відкриється локально у браузері.

## Як залити на хостинг через FileZilla

1. Підключись до хостингу через FileZilla.
2. Відкрий папку `public_html` або `www`.
3. Завантаж усі файли з цієї папки сайту всередину `public_html`.
4. Відкрий свій домен у браузері.

## Як змінити текст

Відкрий `index.html` у VS Code або Блокноті та редагуй потрібні фрази між тегами. Наприклад заголовок, лист, підписи до фото.

## Як замінити фото

Фото лежать у `assets/img/`. Найпростіше — замінити файли з такими самими назвами:

- `portrait-bw.webp`
- `lake-close.webp`
- `kyiv-wide.webp`
- `lake-wide.webp`

Після заміни онови сторінку.
